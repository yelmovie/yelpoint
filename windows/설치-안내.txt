YelPoint 설치와 작업표시줄 고정

1. YelPoint-Setup.exe를 실행해 주세요.
2. 설치 폴더를 확인하고 '설치'를 눌러 주세요.
3. 설치가 끝나면 시작 메뉴(원하면 바탕 화면)에 YelPoint 바로 가기가 생겨요.
4. YelPoint가 실행되면 작업표시줄의 아이콘을 우클릭하고 '작업 표시줄에 고정'을 누르면 다음부터 그 아이콘으로 열 수 있어요.

기본 설치 위치는 이 컴퓨터 사용자 폴더의 AppData\Local\YelPoint예요. 관리자 권한이 없어도 설치돼요.
설치 프로그램을 USB 드라이브에서 실행하면 그 드라이브의 YelPoint 폴더가 기본 위치가 돼요.
Program Files처럼 관리자만 쓸 수 있는 폴더는 고를 수 없어요. 기본 위치나 문서 폴더 아래를 골라 주세요.
설정과 임시 파일, 저장한 캡처·녹화는 설치 폴더의 data에 저장돼요.
USB 드라이브에 설치했다면 드라이브를 뺀 동안에는 고정한 아이콘으로 앱을 열 수 없어요. 연결한 상태로 사용해 주세요.

설치 없이 쓰려면 YelPoint.exe와 YelPoint.exe.config, scrcpy 폴더를 같은 폴더에 두고 실행해도 돼요.

기본 조작
Ctrl+Alt+1: 강조
Ctrl+Alt+2: 돋보기
Ctrl+Alt+3: 펜
Ctrl+Alt+4: 타이머
Ctrl+Alt+5: 캡처
Ctrl+Alt+6: 스팟
Ctrl+Alt+0: 도구막대 숨기기·보이기
Esc: 펜·돋보기·캡처·스팟·QR을 끄고 원래 앱 조작으로 돌아와요. 그린 내용은 남아 있어요.
Alt 누르는 동안: 필기 중 클릭과 스크롤이 아래 앱으로 통과해요.
폰·QR·칠판은 도구막대 버튼으로 열어요.

종료: 도구막대 맨 끝의 전원 버튼(⏻)이나 알림 영역 아이콘을 우클릭해 '종료'를 눌러 주세요. 화면에 필기가 있으면 한 번 더 물어봐요.
제거: Windows 설정 → 앱 → 설치된 앱에서 YelPoint를 제거해 주세요. 프로그램 파일과 바로 가기는 지우고 data 폴더는 남겨 둬요.
data 폴더까지 지우면 저장한 설정과 캡처·녹화도 지워져요.

Windows 10/11 64비트, .NET Framework 4.8 환경용이에요.

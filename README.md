# YelPoint

수업·강의·유튜브 설명 영상을 위한 작은 화면 도구야. 화면 아래의 **강조 · 돋보기 · 펜 · 타이머 · 캡처 · 스팟** 버튼으로 사용해.

## 실행 파일

| 운영체제 | 파일 | 지원 환경 |
|---|---|---|
| 맥 | `YelPoint-macOS.zip` 안의 `YelPoint.app` | macOS 14 이상, Apple Silicon·Intel |
| 윈도우 | `YelPoint-Setup.exe` | Windows 10·11 64비트(x64), .NET Framework 4.8 |
| 윈도우 무설치 | `YelPoint-Windows.zip` 안의 `YelPoint.exe` | 위와 동일 |

`YelPoint-1.0.0.zip`에는 맥과 윈도우 버전이 함께 들어 있어. 설치·실행 파일과 설정을 외장 SSD에 둘 수 있도록 구성했어.

## 맥에서 시작하기

1. 맥용 ZIP을 **외장 SSD에서** 압축 해제해.
2. `YelPoint.app`을 더블클릭해. 화면 아래에 도구막대가 나타나.
3. Dock의 YelPoint 아이콘을 우클릭하고 **옵션 → Dock에 유지**를 골라.
4. 돋보기·캡처·녹화를 처음 쓸 때 안내창의 **설정 열기**를 누르고 YelPoint 스위치를 켠 다음 **앱 다시 시작**을 눌러. 설정 화면은 앱이 바로 열어 주고, 안 맞는 예전 권한 기록은 앱이 먼저 지워.
5. 녹화에 목소리를 넣으려면 처음 녹화할 때 **마이크** 권한을 허용해. 허용하지 않으면 소리 없이 녹화해.
6. ‘단축키 표시’ 옵션을 쓰려면 **손쉬운 사용** 권한도 허용해. 강조와 필기만 사용할 때는 이 권한이 필요 없어.

외장 SSD에서 실행하면 설정과 저장 파일이 앱 옆 `data`에 생겨. `.app`을 `/Applications`처럼 내장 드라이브에 설치하면 설정은 `~/Library/Application Support/YelPoint`, 저장·녹화 파일은 `~/Movies/YelPoint`에 생겨.

## 윈도우에서 설치하기

1. 외장 SSD에 `YelPoint-Setup.exe`를 놓고 실행해.
2. 설치 폴더를 확인하고 **설치**를 눌러. 기본 위치는 설치 파일이 있는 드라이브의 `YelPoint` 폴더야.
3. 설치된 앱을 실행해.
4. 작업표시줄의 YelPoint 아이콘을 우클릭하고 **작업 표시줄에 고정**을 골라.

관리자 권한이나 브라우저 설치는 필요 없어. 설치 프로그램은 선택한 폴더에 파일을 복사하고, 기존 `data` 설정은 그대로 둬. 다른 위치로 자동 대체하지 않아. 무설치로 쓰려면 윈도우 ZIP을 풀고 `YelPoint.exe`와 `YelPoint.exe.config`를 같은 폴더에 둔 채 실행해.

## 여섯 가지 도구

| 버튼 | 동작 |
|---|---|
| 강조 | 커서 주변에 노란 동그라미. 왼쪽 클릭은 주황색, 오른쪽 클릭은 파란색으로 잠깐 표시해. |
| 돋보기 | 커서 주변을 실시간으로 확대해. 켜면 막대 위에 1.5×·2×·3×·4×·5× 패널이 떠서 배율을 고를 수 있어. 화면을 멈추지 않고 버튼과 메뉴를 조작할 수 있어. |
| 펜 | 화면 위 자유 필기. 보조 도구막대에서 색 3개·원형 색상환·굵기 슬라이더(1~30)·되돌리기·전체 지우기를 선택해. 색상환 아래 막대로 밝기를 바꿔. |
| 타이머 | 1~60분 카운트다운. 숫자 칸에 분을 직접 입력하거나 −/+, 5·10·30·60으로 맞추고 ▶로 시작해. 남은 시간 시계는 끌어서 어디든 옮기고, 오른쪽 아래 모서리를 끌어 크게 키울 수 있어. 위치와 크기는 기억해. 끝나면 ‘펑’ 소리와 함께 터지듯 사라져. 효과음은 이 앱용으로 직접 합성했어. |
| 캡처 | 영역(커서가 카메라 십자 모양으로 바뀌고 화면에 안내가 떠. 드래그 캡처 후 클립보드 복사. 캡처한 조각이 그 자리에 고정되고 펜이 바로 켜져서 그 위에 필기할 수 있어. 필기는 이미지에 붙어서 같이 움직이고 저장할 때 합쳐져) 붙인 이미지에서 마우스 오른쪽 버튼을 누르면 글자 넣기·복사하기·복사해서 바로 붙여넣기·저장·닫기가 나와. 글자 넣기는 그 자리에 타이핑하고 Enter. 복사하기는 필기와 글자까지 합쳐서 복사하고 펜을 꺼 주니, 붙여넣을 곳을 클릭하고 ⌘V·Ctrl+V를 누르면 돼. 복사해서 바로 붙여넣기는 지금 쓰던 앱(PPT 등)에 바로 붙여 줘. 맥에서는 손쉬운 사용 권한이 필요해. 붙이기는 마우스가 있는 모니터에 띄워. · 붙이기(복사한 이미지를 화면에 띄움) · 저장(PNG) · 녹화(마이크 포함 MP4). |
| 스팟 | 사각·원·타원을 고르고 드래그하면 그 자리에 빨간 선이 남아. 화면은 어두워지지 않아. 손을 뗀 뒤 빨간 선을 끌어 크기를 바꾸고 안쪽을 끌어 옮겨. 바깥을 클릭하거나 Esc를 누르면 편집이 끝나고, 스팟은 남은 채 아래 앱을 그대로 조작할 수 있어. 끄기로 없애. |

붙인 이미지는 끌어서 옮기고 ✕로 닫아. 펜으로 그 위에 필기할 수 있어. 캡처에는 필기와 타이머가 함께 찍히고 도구막대는 찍히지 않아.

도구막대는 버튼을 잡고 끌어도 화면 위아래 좌우 어디든 옮겨지고, 놓은 자리를 기억해. 끌다가 화면 왼쪽이나 오른쪽 끝에 닿으면 손을 떼기 전에 바로 세로로 서서 가장자리에 붙고, 패널은 막대 옆으로 열려. 안쪽으로 끌어내면 바로 가로로 돌아와. 오른쪽 끝의 눈 버튼을 누르면 막대가 작은 동그라미로 줄어들어. 동그라미는 끌어서 옮기고, 누르면 다시 펴져. 숨겨도 필기·타이머·스팟은 그대로야. 막대를 잃어버리면 메뉴 막대 아이콘의 **도구막대 보기**를 눌러. **Esc는 필기·확대를 끝내고 조작 모드로 돌아와. 필기는 그대로 남아.** 지우기는 휴지통 버튼으로 해.

필기 중 **맥은 Option, 윈도우는 Alt를 누르는 동안** PPT를 넘기거나 웹페이지를 클릭·스크롤할 수 있어. 키를 놓으면 다시 필기해.

| 동작 | 맥 | 윈도우 |
|---|---|---|
| 강조 켜기·끄기 | Control+Option+1 | Ctrl+Alt+1 |
| 돋보기 켜기·끄기 | Control+Option+2 | Ctrl+Alt+2 |
| 펜 켜기·끄기 | Control+Option+3 | Ctrl+Alt+3 |
| 타이머 패널 열기·닫기 | Control+Option+4 | Ctrl+Alt+4 |
| 캡처 패널 열기·닫기 | Control+Option+5 | Ctrl+Alt+5 |
| 스팟 패널 열기·닫기 | Control+Option+6 | Ctrl+Alt+6 |
| 도구막대 숨기기·보이기 | Control+Option+0 | Ctrl+Alt+0 |
| 조작 모드로 복귀 | Esc | Esc |

다른 앱이 단축키를 쓰고 있으면 도구막대 버튼으로 사용할 수 있어.

## 언어

간단 설정의 **언어 / Language**에서 한국어와 English를 고를 수 있어. 고르면 앱이 자동으로 다시 시작되고, 앱 문구와 사용법 영상이 함께 바뀌어. 윈도우 설치 프로그램은 Windows 언어를 따라가.

## 사용법 영상

설정의 **사용법**을 누르면 기능별로 움직이며 보여 주는 1분짜리 영상이 열려. 왼쪽 목록을 누르면 강조·펜·스팟 같은 섹션으로 바로 건너뛰고, **이전·다음** 버튼이나 ←/→ 키로 한 섹션씩 넘길 수 있어. 맥은 앱 안 창에서, 윈도우는 기본 브라우저에서 열려. 영상에 소리는 없어.

## 크기 조절

**Control(윈도우는 Ctrl)을 누른 채 스크롤**해. 위로 굴리면 크게, 아래로 굴리면 작게 바뀌어. 강조 버튼 위에서는 키 없이 스크롤해도 돼. 도형 스팟이 있으면 스팟, 없고 ‘주변 어둡게’가 켜져 있으면 그 밝은 원, 둘 다 아니면 노란 포인터 크기를 바꿔. 맥에서는 아래 창도 함께 스크롤돼.

## 간단 설정

- **단축키 표시:** `⌘C`, `Ctrl+C`처럼 보조키가 있는 조합만 화면에 잠깐 표시해. 일반 문장 입력이나 키 입력 기록 파일을 저장하지 않아.
- **필기 자동 지우기:** 이 옵션을 켠 후 그린 선은 4초 뒤 사라져. 문제 풀이를 남길 때는 꺼.
- **주변 어둡게:** 커서 주변만 밝게 두어 시선을 모아.

앱에서 직접 저장하는 설정은 앱 옆 **`data/settings.json`**에 있어. 화면 캡처 프레임은 돋보기에 표시하는 동안 메모리에서 처리해. 이미지·동영상 파일로 자동 저장하지 않아. **저장**이나 **녹화** 버튼을 눌렀을 때만 `YelPoint-날짜-시각.png`·`.mp4`로 저장해. 위치는 외장 SSD 실행이면 앱 옆 **`data/captures`**, 맥에 설치했으면 **`~/Movies/YelPoint`**야.

## 폰 연결 (안드로이드 폰·태블릿)

도구막대의 **폰**을 누르면 패널이 열려. 안드로이드 폰이나 태블릿을 USB 데이터 케이블로 꽂으면 화면을 띄우고, **카메라**를 누르면 폰 뒤 카메라가 실물화상기가 돼. 회전·조명(플래시)·멈춤(지금 장면을 고정해 바로 필기)·끄기를 쓸 수 있어.

- 처음 한 번: 폰 설정에서 빌드번호를 7번 눌러 개발자 옵션을 열고 **USB 디버깅**을 켠 뒤, 꽂았을 때 뜨는 허용 창에서 **항상 허용**.
- 한 번 연결하면 다음부터는 꽂기만 해도 바로 떠(패널의 ‘꽂으면 바로 띄우기’로 끌 수 있어).
- 카메라는 안드로이드 12 이상. 아이폰·아이패드는 지원하지 않아.
- 함께 넣은 [scrcpy 5.0.1](https://github.com/Genymobile/scrcpy)(Apache 2.0)와 adb를 수정 없이 사용해. 키·로그·임시 파일은 YelPoint 데이터 폴더 안 `android/`에만 둬. 자세한 내용은 `THIRD-PARTY-NOTICES.txt`.

## 녹화 자막

녹화를 마치면 자막을 넣을지 물어봐. 캡처 패널의 **자막**으로 예전 녹화도 고를 수 있어.

- **맥**: 영상 미리보기 아래에서 자막 줄(시작·끝·글)을 고쳐. **말소리로 자동 만들기**는 macOS 음성 인식(가능하면 기기 안에서 처리)으로 초안을 만들어. 처음에 음성 인식 권한을 물어봐. **자막 넣은 영상 저장**은 `이름.subtitled.mp4`(글자를 영상에 새김)와 `이름.srt`를 만들어.
- **윈도우**: 영상을 보며 **지금 위치에 자막**으로 넣고 **SRT 저장**. 같은 이름의 `.srt`는 VLC·윈도우 미디어 앱·유튜브가 자막으로 읽어. 영상에 글자를 새기는 기능은 윈도우 실기기 검증 뒤에 넣을 예정이야.
- 자막 글꼴: [나눔고딕](https://github.com/google/fonts/tree/main/ofl/nanumgothic) Bold (SIL OFL 1.1). 고친 자막은 `이름.subtitles.json`에 저장돼서 다시 열어도 남아 있어.

## QR 코드

도구막대의 **QR**을 누르고 주소를 붙여넣은 뒤 Enter를 누르면 화면 가운데에 큰 QR 코드와 주소가 떠. 끌어서 옮기고 ✕나 Esc로 닫아. 맥은 macOS 기본 QR 생성기를, 윈도우는 앱에 들어 있는 생성기(오류 정정 M, UTF-8 213바이트까지)를 써. 윈도우 생성기는 macOS QR 판독기로 디코딩되는지 검사했어(`scripts/check-qr.swift`).

## 칠판

도구막대의 **칠판**을 누르면 나무 틀과 분필 받침이 있는 큰 초록 칠판이 열려. 분필 다섯 색 · 굵게/가늘게 · **글씨**(칠판을 클릭하고 한글·영어 입력 → 손글씨 분필로 남음) · 지우개 · 되돌리기 · 모두 지우기 · 저장(PNG) · 닫기. 손글씨 글꼴은 [나눔손글씨 펜](https://github.com/google/fonts/tree/main/ofl/nanumpenscript)(SIL OFL 1.1)을 수정 없이 넣었어.

## 녹화와 종료

내장 녹화는 도구막대가 있는 화면 전체를 찍어. 필기·타이머·붙인 이미지·커서는 찍히고 도구막대는 찍히지 않아. **기본 마이크 소리는 함께 녹음하고, 컴퓨터에서 나는 소리는 녹음하지 않아.** 멈출 때는 캡처 → 정지를 눌러.

윈도우 녹화는 초당 15프레임이야. Windows 10 2004 이전에서는 도구막대도 함께 찍혀. N 에디션은 미디어 기능 팩을 설치해야 해. **윈도우 녹화는 실제 Windows에서 아직 실행해 보지 않았어.** 중요한 수업에 쓰기 전에 짧게 시험해 줘.

OBS에서는 **전체 화면 캡처**를 선택하고 짧게 시험 녹화해. 특정 프로그램 창만 캡처하면 별도 창인 강조·필기가 함께 찍히지 않을 수 있어.

도구막대 맨 끝의 **전원 버튼(⏻)**을 누르면 바로 종료돼. 맥 메뉴 막대 아이콘이나 윈도우 알림 영역 아이콘에서도 종료할 수 있어. 제거할 때는 앱을 종료하고 설치 폴더를 삭제해. Dock·작업표시줄 고정도 해당 아이콘 메뉴에서 해제하면 돼.

## 검증 범위

맥은 Universal 빌드·코드 서명·실행/종료·모델/자체 UI 검사를 통과했어. 자체 검사는 막대 이동·숨기기, 포인터 크기, 색상환, 도형 스팟, 타이머, 영역 선택, 붙이기, PNG 저장, 합성 화면·무음으로 만든 MP4 영상·오디오 트랙 쓰기까지 포함해. 화면 기록과 손쉬운 사용 권한을 자동으로 승인하지 않았으므로, 실제 돋보기·영역 캡처·화면 녹화·마이크 녹음과 영상 싱크·키보드 표시·OBS 녹화는 사용자 환경에서 시험이 필요해.

윈도우는 경고 없는 컴파일, 설치 파일 구성, 실제 모델 소스를 사용한 설정 저장·복구·필기 시간·타이머·포인터 크기·색상환·스팟 계산 검사까지 통과했어. 이 Mac에서 Windows GUI를 실행하지 않았으므로 실제 필기·돋보기·막대 이동·숨기기·포인터 크기·색상환·스팟·타이머 표시·캡처·붙이기·저장·녹화·마이크·다중 배율·작업표시줄 고정은 Windows PC에서 확인해야 해.

## 소스와 빌드

- `macos/`: Swift·AppKit·ScreenCaptureKit 앱. macOS 14부터 동작하는 Universal 실행 파일.
- `windows/`: WinForms·Windows Magnification API 앱과 설치 마법사. x64 .NET Framework 4.8 실행 파일.
- `scripts/`: 외장 SSD를 검증하는 빌드 환경, 아이콘 생성, 사용법 영상 렌더링(`make-guide.sh`), 양쪽 빌드, 배포 파일 묶기. 기능을 바꾸면 `make-guide.sh`를 다시 돌려.
- `previews/spotmouse-preview.html`: 사용자가 선택한 도구막대 샘플.

이 Mac에서는 다음 순서로 빌드해. 캐시·컴파일러·임시 파일은 실제 외장 SSD에 저장된 `/Volumes/REA` APFS 이미지 안에 둬.

```sh
sh '/Volumes/T7 Shield/rea/spotmouse/scripts/make-icons.sh'
sh '/Volumes/T7 Shield/rea/spotmouse/scripts/build-macos.sh'
sh '/Volumes/T7 Shield/rea/spotmouse/scripts/build-windows.sh'
sh '/Volumes/T7 Shield/rea/spotmouse/scripts/package.sh'
```

직접 실행으로 확인한 범위와 Windows에서 추가 확인할 항목은 `reports/`의 검증 기록에 남겨.

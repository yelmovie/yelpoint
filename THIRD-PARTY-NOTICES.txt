YelPoint 함께 넣은 외부 프로그램 / Third-party software in YelPoint

YelPoint의 코드·아이콘·효과음은 yelsam.lab이 직접 만들었습니다.
안드로이드 폰·태블릿 화면과 실물화상기 기능에는 아래 오픈소스 프로그램을 수정 없이 함께 넣었습니다.
YelPoint's own code, icons and sounds are by yelsam.lab. The Android screen and document
camera feature ships the following open-source programs unmodified.

1. scrcpy 5.0.1 — Copyright (C) 2018 Genymobile, Copyright (C) 2018-2026 Romain Vimont
   License: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
   Source: https://github.com/Genymobile/scrcpy (release v5.0.1)

2. adb (Android Debug Bridge, Android SDK Platform-Tools) — The Android Open Source Project
   License: Apache License 2.0
   Source: https://android.googlesource.com/platform/packages/modules/adb/

3. Libraries used by scrcpy (linked into the macOS scrcpy program, separate DLLs on Windows)
   - FFmpeg — GNU Lesser General Public License 2.1 or later — https://ffmpeg.org/download.html
   - SDL 3 — zlib License — https://github.com/libsdl-org/SDL
   - libusb — GNU Lesser General Public License 2.1 or later — https://github.com/libusb/libusb
   The LGPL libraries are the unmodified builds published with scrcpy v5.0.1. Their source code
   is available at the links above and from the scrcpy release page. On Windows they are
   separate DLL files that can be replaced with compatible versions.

4. Nanum Pen Script (칠판 손글씨 / chalkboard handwriting) — Copyright (c) 2010, NHN Corporation
   License: SIL Open Font License 1.1 — the full license follows at the end of this file.
   Source: https://github.com/google/fonts/tree/main/ofl/nanumpenscript (unmodified)

5. Nanum Gothic Bold (자막·칠판 고딕 / subtitles and board sans) — Copyright (c) 2010, NHN Corporation
   License: SIL Open Font License 1.1 (same license text as below; reserved font names include NanumGothic)
   Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic (unmodified)

6. Nanum Myeongjo Bold (칠판 명조 / board serif) — Copyright (c) 2010, NHN Corporation
   License: SIL Open Font License 1.1 (same license text as below; reserved font names include NanumMyeongjo)
   Source: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo (unmodified)
